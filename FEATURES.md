# Features (0.3 Shelf Revamp)

See [docs/PRODUCT.md](./docs/PRODUCT.md) and [docs/CHANGELOG.md](./docs/CHANGELOG.md) for the source of truth.

## Daily loop

1. **Park** — Save open tabs to Later or a named shelf (choose which tabs; closing is optional)
2. **Find** — Search or filter shelves
3. **Restore** — Open one tab or a whole shelf

## Included

- Later inbox (auto-created)
- Named shelves: pin, rename, delete, merge
- Park modal with partial selection
- Move tab between shelves
- Search (⌘/Ctrl+K)
- List / grid views
- Duplicate open-tab cleanup
- Sort by site (domain grouping)
- Local-first storage
- Optional Google sync + sync status chip
- Settings (appearance, behavior, account, export/import)
- Onboarding tip strip
- Context menus: Open / Save all / Save this tab

## Not included

Tags, notes, AI summaries, side panel, new-tab page, multi-window park, collaboration
